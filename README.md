# Carmendation
Carmendation is a car reccomendaiton site made by a car enthusiast, ensuring every car in the dataset are cars worth getting!
Each car is scored based on how many preferences matched/partly matched the linear search algorithm
The UI is simple, works in the terminal, a user can simply just press enter if they have no preferences, or choose one or more of the shown factors for a more personalized experience

This is Joe Sherif's portfolio project made with the help of codecademy!
